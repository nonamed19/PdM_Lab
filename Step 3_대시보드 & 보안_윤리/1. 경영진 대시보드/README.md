# 경영진 대시보드 (HTML + JavaScript)

**질문:** 분석 결과를 HTML + JavaScript 경영진 대시보드로 만들어줘. (1) 상단 KPI 4개(고장률 / 모델 재현율 / 연간 순절감액 / ROI), (2) 중단 좌: 고장 유형별 도넛 차트, (3) 중단 우: 관측 샘플 순서에 따른 센서값 라인 차트, (4) 하단 좌: Feature Importance 막대그래프, (5) 하단 우: 혼동행렬 히트맵. 모델·임계값·평가 건수를 표시하고 기존 결과와 숫자를 대조해줘. AI4I의 순번은 실제 시간이 아니므로 실시간 모니터링이나 고장 전 추세로 표현하지 말고, 순절감액은 운영비 차감 후 금액이며 ROI와 함께 비용 시나리오로 표시해줘. 다크 테마·한국어·반응형으로 만들고 브라우저에서 동작을 확인해줘.

**답변:** 서버 없이 열리는 [dashboard.html](dashboard.html)을 만들었고, 화면에 쓴 숫자 19개를 원본 결과 파일에서 다시 계산해 기존 보고서 수치와 **모두 일치**함을 확인했습니다.

> ⚠️ AI4I 2020 **합성 데이터** 기반 분석입니다. 실제 설비 성능이나 절감 실적이 아닙니다. 샘플 번호(UDI)는 **실제 시간이 아니며**, 이 화면은 실시간 모니터링도 고장 전 추세 표시도 아닙니다. 모델 성능은 Test 라벨을 보며 임계값을 고른 결과여서 독립 평가가 아닙니다. 비용은 가정에 기반한 시나리오이고 초기 구축비는 포함하지 않았습니다.

- 대시보드: [dashboard.html](dashboard.html) (데이터가 파일 안에 포함됨, 약 330 KB)
- 빌드 코드: [build_dashboard.py](build_dashboard.py) + [dashboard_template.html](dashboard_template.html) — 원본 결과 파일에서 숫자를 읽어 내장하고 대조 `assert`를 통과해야 저장됩니다.

### 주의할 점
- **샘플 번호 순서의 패턴은 시간이 아닙니다.** 라인 차트에서 샘플 4,000~4,999번 구간에 고장이 134건(13.4%)으로 몰려 있고(다른 1,000개 구간은 17~29건), 공구 마모는 톱니 모양으로 보입니다. 합성 데이터의 순번 구성에서 나온 모양이며 고장 전 징후나 시간 추세가 아닙니다. 고장이 평균의 2배 넘게 몰린 구간을 보면 화면이 이 사실을 경고 문구로 알려줍니다.
- 재현율 85.3%는 Test 라벨을 보며 고른 임계값 0.44에서의 값입니다. 기본 임계값 0.5에서는 82.4%입니다(화면의 KPI 설명과 혼동행렬 전환에서 확인 가능).
- 순절감액 23.69억 원은 운영비 2억 원을 **차감한 후** 금액이며 실제 실적이 아닙니다.
