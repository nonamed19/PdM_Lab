# 발표용 인터랙티브 HTML 보고서 (5장) + PDF

**질문:** 앞에서 만든 경영진 대시보드와 분석 결과로, 발표하면서 조작하는 5장짜리 HTML 보고서를 만들어줘. 슬라이드는 (1) 핵심 요약, (2) 문제 발견, (3) 예측 성과(RF/XGBoost 선택 시 지표·혼동행렬 변경), (4) 기대효과(예방 이익에서 정비비·점검비·운영비 차감, 기존 민감도 범위에서 고장 비용 선택 시 절감액·ROI·차트 변경), (5) 도입 제안(3단계 로드맵, 확인한 성과, 추가 검증)으로 구성하고, 16:9·한국어·짙은 남색/청록색, 화면 전환·수치 카운트업·차트 순차 등장·클릭 상세, 방향키·이전/다음·페이지·진행률·전체화면, 화면 크기에 맞춰 잘리지 않게 해줘. 'PDF로 저장' 버튼은 브라우저 인쇄창을 열고 가로 한 페이지에 한 장씩 정확히 5페이지로, 애니메이션 완료 상태와 현재 선택 조건을 반영하고, 버튼·툴팁은 숨기고, 저장 후 원래 화면·선택 상태로 복귀해야 해. 기존 수치·계산식만 사용하고 측정값과 가정값을 구분하고, 단일 `executive_presentation.html`과 샘플 PDF를 저장하고, HTML 5장과 PDF 5페이지를 실제로 열어 한글 깨짐·겹침·잘림·빈 페이지와 모든 상호작용을 확인하고 수정해줘.

**답변:** 서버·API 없이 열리는 [executive_presentation.html](executive_presentation.html)(약 36 KB)과 샘플 [executive_presentation_sample.pdf](executive_presentation_sample.pdf)(5페이지)를 만들었습니다. 슬라이드에 쓴 수치와 계산식 **57개 항목을 기존 결과와 대조해 모두 일치**했습니다.

> ⚠️ AI4I 2020 **합성 데이터** 기반 교육용 분석입니다. 실제 설비 성능·절감 실적이 아닙니다. 결과는 **현재 관측의 정상·고장 분류**이며 미래 고장의 사전 탐지 성과가 아닙니다. 재현율 기준 임계값은 Test에서 고른 **탐색적 값**이라 독립 평가가 아니고, 순절감액은 **운영비 차감 후** 금액이며 초기 구축비는 포함하지 않았습니다.

- 샘플 PDF 생성: [make_sample_pdf.py](make_sample_pdf.py) (브라우저 인쇄와 같은 경로) · 수치 대조표: [number_check.csv](number_check.csv)

## 슬라이드 구성과 조작

| # | 내용 | 조작 |
|---|---|---|
| 1 핵심 요약 | PoC 목적, 핵심 수치 3개(재현율 85.3% **측정·탐색적**, 연간 순절감액 23.69억 원, ROI 1,184.5% **가정 기반**), 결론 한 문장 | 순절감액·ROI는 슬라이드 4에서 고른 고장 비용을 따라감 |
| 2 문제 발견 | 정상 9,661 : 고장 339(3.39%, 약 28.5 : 1) 도넛, 고장 유형별 건수 막대(HDF 115·OSF 98·PWF 95·TWF 46·RNF 19), 주요 발견 3개 | 유형 막대를 누르면 오른쪽에 특징·Test 분류 건수, 도넛·막대에 마우스를 올리면 상세 수치 |
| 3 예측 성과 | Accuracy·Precision·Recall·F1·ROC-AUC·PR-AUC 막대와 혼동행렬 | **모델(랜덤포레스트/XGBoost)**과 **임계값(기본 0.5/재현율 ≥ 0.85 기준 탐색적)** 선택 시 지표·혼동행렬이 함께 변경, 칸을 누르면 의미·비율 |
| 4 기대효과 | 예방한 고장 비용 → 예방 정비비·오경보 점검비 차감 → 절감액(운영비 차감 전) → 운영비 차감 → **연간 순절감액**(워터폴), 오른쪽에 순절감액·ROI·손익분기 | **고장 비용 3,000~8,000만 원**(기존 민감도 범위) 선택 시 워터폴·순절감액·ROI·막대가 함께 변경, 단계를 누르면 계산식 |
| 5 도입 제안 | 3단계 로드맵(~3개월 파일럿 → ~6개월 확대 → ~12개월 고도화), 확인한 성과(측정/가정 구분), 현장 추가 검증, 제안 | — |

- **선택 조건 명시:** 모든 슬라이드 하단에 현재 선택(모델·임계값·고장 비용·평가 건수)과 측정/가정 구분 칩을 표시합니다. 슬라이드 3은 선택한 모델·임계값, 슬라이드 4는 선택한 고장 비용을 보여줍니다.
- **슬라이드 4의 모델:** 기존 비용 시나리오가 랜덤포레스트(임계값 0.44, TP 58·FP 41)로만 계산돼 있어서, 기존 계산식만 쓴다는 원칙에 따라 슬라이드 4는 이 조건으로 고정했습니다. 슬라이드 3에서 XGBoost를 골라도 슬라이드 4의 비용은 바뀌지 않습니다(XGBoost 기준 비용은 계산한 적이 없음).
- **내비게이션:** ← → ↑ ↓ PageUp/PageDown, Home/End, **F(전체화면)**, 이전/다음 버튼, "n / 5" 쪽수, 상단 진행률 막대. 16:9 무대가 화면 크기에 맞춰 비율을 유지하며 줄어들어 잘리지 않습니다.
- **효과:** 슬라이드 전환(페이드·슬라이드), 숫자 카운트업, 차트 순차 등장(막대 성장·도넛 그리기·워터폴 순서). 시스템의 "동작 줄이기" 설정을 켜면 효과 없이 바로 표시합니다.

## PDF 저장

`PDF로 저장` 버튼 → 모든 숫자를 최종값으로 확정하고 인쇄 상태로 전환 → 브라우저 인쇄창(대상: PDF로 저장, 여백 없음) → 인쇄 후 원래 슬라이드·선택 상태로 복귀합니다. Ctrl+P로 직접 인쇄해도 같은 인쇄용 레이아웃이 적용됩니다.

- 인쇄 레이아웃: 용지 1280×720 CSS px(16:9 가로), 슬라이드 1장 = 1페이지, 이동 버튼·툴팁·도움말 숨김, 배경색 포함, 한글은 글꼴 포함 선택 가능한 텍스트, 차트는 SVG 벡터.
- 인쇄창의 "배경 그래픽"은 켜져 있어야 짙은 남색 배경이 나옵니다(버튼으로 연 인쇄창에서는 페이지가 이를 요청하지만, 브라우저가 기본값으로 끌 수 있으니 확인하세요).

## 주의
- 슬라이드 2의 고장 유형별 규칙(8.6 K, 1,380 rpm, 3,500~9,000 W 등)은 **합성 데이터의 생성 규칙**이며 실제 설비 기준이 아닙니다.
- 성과·비용 수치의 한계(탐색적 임계값, 합성 데이터, 100% 예방 가정, 구축비 미포함)는 각 슬라이드 하단 문구로도 표시했습니다.
- 헤드리스 환경에서는 실제 인쇄 대화상자를 열 수 없어서, 'PDF로 저장' 버튼의 동작은 인쇄 호출·상태 진입·복귀를 확인했고 PDF 내용은 같은 인쇄 경로로 만들어 검증했습니다. 사용자 브라우저의 인쇄 대화상자에서는 용지 크기·배경 그래픽 설정을 한 번 확인해 주세요.
