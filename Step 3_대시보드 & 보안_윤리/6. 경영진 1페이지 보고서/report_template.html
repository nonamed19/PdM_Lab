CNC 밀링 센서 데이터(AI4I 2020 공개 합성 데이터) 기반 · 교육용 분석 결과 요약
본 결과는 센서가 관측된 시점의 정상·고장 분류 성능이며, 미래 고장의 사전 탐지 성과가 아닙니다. 합성 데이터 기반이므로 실제 설비 성능·절감 실적이 아닙니다. 임계값은 Test에서 고른 탐색적 결과입니다.

1Executive Summary

  • 랜덤포레스트가 원본 Test %%TEST_N%%건에서 고장 %%TEST_F%%건 중 %%TP%%건을 고장으로 분류해 재현율 %%REC%%%를 보였으나(임계값 %%THR%%, 탐색적), 놓친 고장 %%FN%%건·오경보 %%FP%%건이 남았습니다.
  • 연 %%ANN_N%%건·탐지 고장 100%% 예방·고장 %%CF%% 등 가정 하에서 운영비 차감 후 연간 순절감액은 %%NET%%억 원(ROI %%ROI%%%)이며, 실적이 아닌 시나리오(초기 구축비 미포함)입니다.
  • 합성 데이터 결과이므로, 3개월 파일럿에서 별도 검증 데이터로 임계값·성능·예방률·비용을 실측한 뒤 확대 여부를 판단할 것을 제안합니다.

6리스크와 현장 추가 검증

  • 데이터: 합성 데이터이며 실제 설비 성능이 아님. 일부 입력은 데이터 생성 규칙 기반 파생변수.
  • 평가: 임계값을 Test에서 골라 낙관적, 분할 1회·교차검증 없음.
  • 가정: 연 건수·100%% 예방·비용은 가정. 예방 성공 50%%이면 순절감액 %%NET50%%억 원(ROI %%ROI50%%%).
  • 비용: 초기 구축비 미포함, 손익분기 고장 비용 약 %%BE%%만 원/건.
  • 검증: 별도 검증 데이터에서 임계값 결정 후 미사용 Test로 평가, 시점 분리 검증.
  • 운영: 오경보 대응 부담·책임체계, 라벨 품질, 데이터 변화 모니터링.
  • 보안: 실제 자료는 승인된 환경에서 처리, 외부 AI 사용 전 회사 기준 확인.
  • 설명: 변수 중요도·SHAP은 모델 판단 설명이며 고장 원인의 증명이 아님.
