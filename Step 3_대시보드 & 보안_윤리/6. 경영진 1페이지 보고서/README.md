| 구분 | 내용 | 성격 |
|---|---|---|
| 재현율 | **85.3%** (원본 Test 고장 68건 중 58건), 임계값 0.44 | 측정 · **탐색적**(Test에서 고른 임계값) |
| 놓친 고장 / 오경보 | 10건 / 41건 (기본 0.5: 12건 / 38건) | 측정 |

- **표현 원칙:** 상단에 "센서가 관측된 시점의 정상·고장 분류 성능이며 미래 고장의 사전 탐지 성과가 아님"을 표시했습니다. 로드맵에서도 사전 탐지는 시계열 기반 별도 PoC로 분리했고 이번 결과에 포함하지 않는다고 적었습니다.
- **측정과 가정의 구분:** 핵심 수치 카드에 "측정 · 탐색적"과 "가정 기반" 태그를 붙였고, 하단에 가정(연 건수, 100% 예방, 고장·점검·정비비, 운영비)과 계산식을 적었습니다. 초기 구축비는 포함하지 않았다고 표시했습니다.
- **경보 기준:** 정상 <0.30 · 주의 0.30~0.60 · 경고 0.60~0.85 · 위험 ≥0.85(경계값은 상위 등급), Test 분포 1,866 / 57 / 35 / 42, 확인 SLA(교육용 예시), 에스컬레이션(담당자 → 팀장 → 공장장), 정지 여부는 현장 절차로 판단. 점수는 미보정 출력입니다.
- **로드맵:** ~3개월 파일럿(검증 데이터와 미사용 Test 분리, 소수 라인 현장 검증, 오경보 비용·예방률 실측) → ~6개월 확대(ROI 재계산) → ~12개월 고도화(약점 유형 개선, 확률 보정, 사전 탐지는 별도 PoC).

## 수치 대조 (38개 항목 모두 일치)

수치는 하드코딩하지 않고 원본 결과 파일에서 읽어 채웠고, 앞선 보고서에 적은 값과 `assert`로 비교한 뒤에만 저장됩니다.

| 대조 범위 | 출처 |
|---|---|
| 전체 10,000건, 고장 339건(3.39%) | Step 1 · 1번 |
| 학습 8,000건 → SMOTENC 15,458건, Test 2,000건(고장 68건) | Step 2 · 1번 |
| 임계값 0.44의 TP 58 · FN 10 · FP 41, 재현율 85.3%, 정밀도 58.6% | Step 2 · 4번 |
| ROC-AUC 0.974, 기본 0.5의 재현율 82.4% · FN 12 · FP 38 | Step 2 · 2번 |
| 가정(2,000건·68건·100%·5,000만·100만·500만·운영비 2억 원) | Step 2 · 5번 |
| 절감액 25.69억, 순절감액 23.69억, ROI 1,184.5%, 손익분기 약 916만 원, 예방 50% 시 10.64억(ROI 532.0%) | Step 2 · 5번 |
| 경보 등급 건수 1,866 / 57 / 35 / 42, 위험만 대응 시 놓친 고장 31건(45.6%) | Step 3 · 2번 |

계산식도 다시 계산했습니다. 순절감액 = TP × (고장 비용 − 정비비) − FP × 점검비 − 운영비 = 58 × 4,500만 − 41 × 100만 − 2억 = 23.69억 원, ROI = 23.69 ÷ 2 × 100 = 1,184.5%이며 저장된 계산 결과와 일치합니다.

**이번 보고서에서 새로 계산한 수치:** 공구 마모(TWF) 고장은 Test 10건 중 3건만 분류(임계값 0.44). 기존 표에는 임계값 0.5 기준(2/10)만 있어서 임계값 0.44 기준으로 새로 계산했고, 보고서에 임계값을 함께 적었습니다.
