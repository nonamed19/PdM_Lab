점검 우선순위 보드 (교육용 예시)

랜덤포레스트 예측점수가 높은 관측 샘플부터 점검 순서를 보여줍니다. 등급을 누르면 해당 목록만, 항목을 누르면 센서값·점수·권장 조치가 펼쳐집니다.

점수는 미보정 모델 출력이며 실제 고장 확률이 아닙니다. 조치·SLA·에스컬레이션은 교육용 예시이며 실제 운영 전에 현장 기준으로 검증해야 합니다.
각 행은 관측 샘플 1건입니다(설비 한 대나 설비 ID가 아니며, 샘플 번호는 시간 순서도 아닙니다). 순위는 예측점수만 사용했고 실제 고장 라벨은 쓰지 않았습니다.
위험 등급이라도 설비 정지 여부는 자동으로 결정하지 않습니다. 담당자가 현장 절차에 따라 판단합니다.
