# 점검 우선순위 HTML 보드 (교육용)

**질문:** 앞에서 만든 예측 결과와 경보 등급으로 점검 우선순위 HTML 보드를 만들어줘. (1) 정상·주의·경고·위험 등급별 관측 건수를 색상 카드로 표시, (2) 랜덤포레스트 예측점수가 높은 샘플부터 점검 목록 정렬, (3) 등급을 누르면 해당 목록만, 항목을 누르면 센서값·점수·권장 조치 표시. 기준은 <30% 정상, 30~60% 주의, 60~85% 경고, ≥85% 위험으로 유지하고, 실제 고장 라벨은 점검 순위에 사용하지 말고, 행은 설비 대수가 아닌 관측 샘플로 표시하고, 점수는 미보정 모델 출력이고 조치·SLA는 교육용 예시라고 명시하고, 위험 등급의 정지 여부는 자동 결정하지 않게 해줘. 서버 없이 열리는 `inspection_board.html`로 저장하고 필터·클릭, 건수·점수가 저장된 예측 결과와 맞는지 점검해줘.

**답변:** [inspection_board.html](inspection_board.html)을 만들었습니다. 서버 없이 열리고, 카드 건수와 점수가 저장된 예측 결과와 **모두 일치**함을 브라우저에서 확인했습니다.

> ⚠️ **점수는 미보정 모델 출력이며 실제 고장 확률이 아닙니다.** 조치·SLA·에스컬레이션은 **교육용 예시**이며 실제 운영 전에 현장 기준으로 검증해야 합니다. 각 행은 **관측 샘플 1건**이며 설비 한 대나 설비 ID가 아니고, 샘플 번호는 시간 순서도 아닙니다. 위험 등급이라도 **설비 정지 여부는 자동으로 결정하지 않으며**, 담당자가 현장 절차에 따라 판단합니다. 보드 상단에 모두 표시했습니다.

- 빌드: [build_board.py](build_board.py) + [board_template.html](board_template.html) — 저장된 파일에서 값을 읽어 내장하고 빌드 중에 대조 `assert`를 통과해야 저장됩니다.

### 화면 구성

| 영역 | 내용 |
|---|---|
| 안내 3줄 | 점수 미보정·교육용 예시 / 관측 샘플·라벨 미사용 / 정지 여부 자동 결정 안 함 |
| 등급 카드 4개 | 정상 **1,866건**(점수 < 0.30) · 주의 **57건**(0.30~0.60) · 경고 **35건**(0.60~0.85) · 위험 **42건**(≥ 0.85), 각 전체 대비 비율 |
| 점검 목록 | 랜덤포레스트 예측점수 **내림차순**(점수가 같으면 샘플 번호 순). 순위·샘플 번호·등급·점수 막대·점수·제품 유형. 50건씩 "더 보기" |
| 등급 카드 클릭 | 해당 등급 목록만 표시(같은 카드를 다시 누르거나 "전체 등급 보기"를 누르면 해제) |
| 항목 클릭 | 센서 5개 + 파생변수 3개 값, 예측점수, 점검 순위, **권장 조치(확인 내용·점검 조치·SLA·에스컬레이션)**. 위험 등급은 정지 여부 안내 문구 포함 |
| 샘플 번호 검색 | 번호를 입력해 해당 샘플 찾기 |

- 권장 조치와 SLA는 [Step 3의 2번 폴더](../2.%20교육용%20경보%20기준/alert_policy.csv) 문서를 그대로 읽어 썼습니다.
- **실제 고장 라벨은 HTML에 내장하지 않았습니다.** 순위 계산에도, 화면 표시에도 쓰이지 않습니다(빌드 시 검사).
- 점수는 퍼센트가 아니라 0~1 값 그대로 표시했습니다. 확률로 읽히지 않게 하려는 의도입니다. 카드의 "30~60%" 같은 표기는 등급 이름일 뿐입니다.

### 저장된 결과와의 대조 (모두 일치)

| 점검 항목 | 결과 |
|---|---|
| 카드 건수 (정상/주의/경고/위험) | 1,866 / 57 / 35 / 42 — 저장된 등급 파일과 일치 |
| 행 정렬 | 전처리 Test 원본, 등급 파일, 예측 파일이 같은 행 순서(샘플 번호 일치) |
| 예측점수 | 저장된 `test_predictions_both.csv`의 RF 점수와 동일 |
| 등급 재계산 | 경계값(0.30·0.60·0.85) 규칙으로 다시 계산한 등급이 저장된 등급 2,000건과 일치 |
| 점검 순위 상위 5건 | 저장된 예측점수를 직접 정렬한 결과와 샘플 번호·점수 일치 (샘플 243, 249, 250, 381, 6079 — 모두 1.000) |
| 목록 정렬 | 전체와 등급별 필터 목록 모두 점수 내림차순 |

### 주의할 점
- **점수가 같은 샘플이 많습니다.** 위험 등급 42건 중 9건이 점수 1.000으로 같습니다. 랜덤포레스트는 200그루 투표라 점수가 0.005 단위로 나오기 때문이며, 같은 점수의 순서는 샘플 번호 순입니다. 이 순서에는 의미가 없습니다.
- 목록의 순위는 "예측점수가 높은 순서"일 뿐 고장 가능성의 확정 순위가 아닙니다. Step 3의 2번 폴더에서 확인했듯이 위험 등급만 점검하면 이 Test 기준 고장의 45.6%를 놓칩니다.
- 점검 순위에는 설비 중요도, 정비 비용, 안전 위험 등 현장 정보가 반영되지 않았습니다.
