# 기초 탐색적 데이터 분석(EDA)

**질문:** 제조 설비 예지보전(PdM) 분석 전문가로서 CNC 밀링 머신 센서 데이터(`ai4i2020.csv`)에 대해 (1) 데이터 구조, (2) 기초 통계량, (3) 결측값, (4) Machine failure 분포, (5) 고장 유형별 발생 건수를 한국어 표로 정리해줘.

**답변:** 결측값은 없고, 고장은 전체의 3.39%뿐입니다.
