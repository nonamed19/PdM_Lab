# 정상 vs 고장 센서 탐색 화면 (HTML)

**질문:** AI4I 데이터로 정상과 고장을 직접 비교하는 HTML 탐색 화면을 만들어줘. (1) X·Y축을 센서값/파생변수에서 선택하면 산점도가 바뀌고, (2) 제품 유형 L/M/H와 정상·고장으로 필터링하며, (3) 선택 데이터의 건수·고장률과 센서값 분포를 함께 보여주고, (4) 점을 클릭하면 해당 샘플의 센서값과 실제 고장 여부를 표시해줘. 기본 화면은 temp_diff vs power, 정상=파란색·고장=빨간색이며, 행을 실제 설비 대수나 시간 흐름으로 해석하지 말고 `sensor_explorer.html`로 저장해줘. 축 변경·유형 필터·점 클릭을 실행해서 확인해줘.

**답변:** 서버 없이 더블클릭으로 열리는 `sensor_explorer.html`을 만들고, 브라우저에서 동작을 확인했습니다.

- 파일: [sensor_explorer.html](sensor_explorer.html) (약 760 KB, 데이터 10,000건이 파일 안에 포함되어 인터넷 연결이 필요 없습니다)

> ⚠️ 각 점은 **개별 관측 샘플 1건**입니다. UDI는 단순 일련번호이고, 실제 설비 대수나 시간 흐름을 뜻하지 않습니다. 이 데이터는 합성 데이터이며 파생변수 정의도 합성 데이터 생성 규칙 기반입니다. 화면 상단에도 같은 안내를 표시했습니다.

### 화면 구성

| 영역 | 기능 |
|---|---|
| X축 / Y축 선택 | 센서 5개 + 파생변수 3개(temp_diff, power, tool_torque_interaction) 중 선택. 기본값은 X=temp_diff, Y=power |
| 제품 유형 | L / M / H 체크박스 |
| 상태 | 정상(파란색 ●) / 고장(빨간색 ◆, 약간 크게) 체크박스 |
| 요약 타일 | 선택 샘플 수, 고장 수, 정상 수, 고장률 |
| 산점도 | 마우스를 올리면 가까운 점의 UDI와 값을 툴팁으로 표시, 클릭하면 해당 점에 검은 링 표시 |
| 선택한 샘플 | UDI, 제품 ID/유형, 고장 유형 라벨, 센서 5개와 파생변수 3개 값, 실제 고장 여부 |
| 선택 데이터 요약 | 정상/고장 그룹별 건수와 현재 X·Y 평균 (표) |
| 센서값 분포 | 8개 변수 히스토그램. 정상과 고장을 그룹 내 비율(%)로 겹쳐 표시하고, 현재 X·Y축 변수는 테두리를 진하게 표시 |

- 정상과 고장을 색뿐 아니라 모양(● / ◆)으로도 구분했습니다.
- 축 범위는 전체 데이터 기준으로 고정해서, 필터를 바꿔도 점의 위치 기준이 흔들리지 않습니다.
- 다크 모드 설정을 따라갑니다.
